# CP16+ 使用说明（快速上手）

- 软件版本：**β0.1.5**（发行标记 **B0.1.5**）
- 协议版本：**V1**
- 许可：MIT（随包的 Hamlib 为 LGPL-2.1）

完整说明见项目里的《软件使用手册》与《协议规范》。

## 两种用法

| 方式 | 做法 | 说明 |
|---|---|---|
| 安装包 | 双击 `cp16plus-B0.1.2-<日期>-安装包.exe` | 装到本机，桌面/开始菜单有入口（推荐） |
| 绿色版 | 解压 `cp16plus-B0.1.2-<日期>.zip`，双击 `CP16+ B0.1.2.exe` | 不写注册表，可放 U 盘 |

不需要 .NET、不需要联网、不需要 Node。界面用本机已有的 Edge / Chrome 显示，
两者都没有时退回系统默认浏览器。

## 安装

安装是三步走，任何一步点「不同意」都会直接退出、不写磁盘：

1. 读一段说明（软件来历、协议版本 V1、软件版本 β0.1.1、联系方式）。
2. 读 MIT 许可全文（含随包 Hamlib 的 LGPL-2.1 说明）。
3. 选安装位置：默认 `C:\Program Files\CP16Plus`，也可以自己挑（会记住上次的选择）。

安装**需要管理员权限**，Windows 会弹 UAC，点「是」即可。
程序装在机器级目录，快捷方式建在「所有用户」的开始菜单与公共桌面；
卸载入口在 `设置 → 应用 → CP16+ B0.1.1`。

批量部署：

```bat
cp16plus-B0.1.2-<日期>-安装包.exe --silent --dir "D:\Tools\CP16Plus"
:: 可选 --no-shortcut（不建快捷方式） --no-launch（装完不启动）
```

装不上时看日志：`%TEMP%\cp16plus-setup.log`。

## 目录里的两个 exe

| 文件 | 作用 |
|---|---|
| `CP16+ B0.1.2.exe` | 启动器：挑端口、拉起引擎、开一个没有地址栏的应用窗口；窗口关掉引擎跟着退出 |
| `cp16plus.exe` | 引擎：内置 HTTP 服务 + 采集 + 编解码 + 发射，也是命令行工具 |

同目录还必须有以下运行库（安装包已自带）：`libhamlib-4.dll`、`libusb-1.0.dll`、
`libwinpthread-1.dll`（均为 64 位）。少任何一个都会启动失败。

两个文件必须放在同一目录。

## 界面

顶栏左边三个页面：**主界面 / 原始瀑布图 / 电台**；右边是频率输入、收发状态、
「保存瀑布图」，以及 设置 / 通联日志 / DEBUG。

频率填 kHz（例如 `14074`），只进通联日志的 ADIF（`FREQ = 14.074 MHz`），
不参与调制解调——协议频段是固定的 16 个音。

### 接收

- 「开始接收」直接听声卡，逐行实时出图；WAV 拖进窗口即可回放（同一条流水线）。
- 中间是实时瀑布：横向 16 列 = 16 个音，纵向 = 时间，越往下越新。
- 右侧「存档区」保留最近若干个 10 秒块（默认 3 块），不必暂停就能回看前几块；
  块头标注 `−N / 时间区间 / 字数`，块数可在 设置 → 显示 里改（1–4）。
- 行高 / 亮度 / 配色随时可调。

### 原始瀑布图

点顶栏「原始瀑布图」会**另开一个窗口**，呈现方式与 SDR 软件一致：

- 横轴频率（左低右高）、时间自上而下流；方向与字的点阵一致，所以文字正立；
- 1 帧 = 1 条线，每 20 ms 一行（50 行/秒），不压缩、不把历史挤进一屏；
- 「行高」1×/2×/4×/8×：把每条线占的像素行数加倍（纯复制，不插值），字太扁时调大；
- 范围可调：全带 0–4000 Hz / 协议带 200–1500 / 低段 0–1500 / 16 音 800–1300，或自定义；
- 底部频率刻度、右侧 dBFS 刻度、左侧时间刻度；鼠标移上去显示「频率 · 电平 · 时间」；
- 顶部 RMS / 峰值电平条，用来判断设备是否在工作；「清屏」「存图」按需使用。

### 发射

- 输入报文（ASCII 自动转全角），点阵预览会标出字库里没有的字；
- 默认消息按钮一点即发（CQ / 呼号 / 网格 / TEST / 73），改完呼号网格可在设置里重建；
- 「发射」遵守时序：**不到整十秒不发射**，界面显示还要等几秒；途中按钮变「中断发射」；
- 同步帧默认叠加；「生成 WAV」「发→收自检」只在调试模式出现。

### 设置

- **本台信息**：呼号、网格（保存后按呼号重建默认消息）。
- **音频**：输入设备（收信）与输出设备（发射）都在这里选，另有"输入走系统混音"开关。
- **发射时序**：时差补偿（毫秒，可负），用于抵消射频链路 + 声卡延迟。
- **文件**：保存目录；「保存瀑布图」默认截取时长（15 / 30 / 60 / 自定义，默认 30 s）。
- **显示**：存档区块数（1–4）。
- **调试模式**：显示生成 WAV、发→收自检、同步帧开关。

### 电台（CAT / PTT）

- 协议由 Hamlib 负责（与 JTDX 同源），界面只做映射：型号（264 个）/ 串口 / 波特率。
- **频率不在这里改**：主界面顶栏的频率是唯一入口，改完自动下发并进日志。
- 「测试 CAT 连接」：不发射，只读一次频率/PTT，失败时说明原因。
- 发射期间不发 CAT 查询（会打断某些机型），并每 2.5 秒补发一次 PTT；
  鼠标停在"发射中"上可看补发次数。
- 勾「启用 CAT」后：发射前按提前量拉 PTT、播完按延时松开；关软件、重连、
  手动 PTT 超过 30 秒都会自动松。
- 协谷 X6100：型号搜 `X6100`，串口选它的 USB 串口，波特率按机器菜单（原厂 19200）；
  填错也会用 19200/9600/38400… 依次试，成功的那档自动写回。
- 提示里会写「实际串口 / 速率」；与你选的不一样，说明串口被别的软件（JTDX、日志软件）占着。

### 通联日志

- 收到报文头时自动登一条（备注标"自动（机读层）"）；频率取顶栏当前值，可逐条改。
- 「导出 ADIF」按 ADIF 3.1.4 写 `.adi` 到保存目录。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击后没窗口 | 确认浏览器可用（Edge/Chrome）；安全软件拦子进程时放行 |
| 报 `0xc000007b` 无法启动 | DLL 位数不对或被截断：运行安装目录里的 `诊断-启动失败.ps1`，按输出处理；详见文档《故障-0xc000007b》 |
| 点按钮没反应 | 装当前版本；地址栏加 `#static-selftest` 可自检 |
| 瀑布一直是黑的 | 检查输入设备、电台音量/声卡增益；用「原始瀑布图」看噪声底 |
| 字能看见但读不出 | 换更慢档位（M4/M8）、加大重复、调大行高 |
| CAT 报串口打不开 | 串口被占用 / 端口号错 / 驱动没装；提示里会显示实际串口与速率 |
| 发射到一半电台停 | 已内置 PTT 保活；仍出现请查电台菜单里的 TX 时限 / VOX |
| 桌面/开始菜单没快捷方式 | 用安装包重装；安装目录里有 `cp16plus.ico` 可自建 |
