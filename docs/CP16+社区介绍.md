# CP16+：用频谱"写"汉字的低速通信协议

面向业余无线电社区的介绍
协议版本 **V1** · 软件版本 **β0.1.2**（发行标记 B0.1.2）· 作者 BD8DQS · 许可 MIT

## 一句话

把汉字排成 16×16 点阵，用 16 个等间距音频单音"画"到频谱上；接收端不需要解码器，
**盯着瀑布图用眼睛读**。机读层只负责呼号、网格、档位这些参数，正文永远只由人眼承载。

## 和 CP16 是什么关系

CP16 是同一思路的早期版本：16 个音、固定的行速、参数在报文头里只传一次。
CP16+ 是它的重写，改的是"骨架"而不是"想法"：

| 项目 | CP16 | CP16+ |
| --- | --- | --- |
| 行速 | 固定 | 档位化（`k = Δf · T_row`，M1/M2/M4/M8 四档，另有两种共存布局） |
| 参数 | 报文头里传一次 | 除报文头外，**每 10 秒**还有一帧同步帧（含字符计数、呼号校验） |
| 纠错 | 无 | 控制信道用 DQPSK + 卷积码 + CRC-16 |
| 定时 | 接收端自己找 | 导频定标 + 控制信道锚定，明确"一行 = 5k 个符号" |
| 字库 | — | CPF1 容器，16×16，覆盖 GB2312 全部 7445 字 |

两者**帧结构不同、互不识别**（同期还有 CP16E，也不兼容）。CP16+ 不是补丁，是新一版协议；
熟悉 CP16 的人会立刻认出那 16 个音，但收发两端都要换。

## 设计思路

1. **人眼优先。** 判定 0/1 的工作交给视网膜而不是 DSP。信号弱时字迹变淡，
   而不是"解码失败、一个字符都没有"——可以慢慢抄，抄一半也有收获。
2. **机读层只带参数。** 呼号、网格、字符数、档位走控制信道，正文不进机读层。
   即使机读层全丢，人眼照样能抄下内容。
3. **用时间换可靠。** 单字 0.68–5.44 s 六种节奏，另可把每一行重复 2–3 次"描粗"笔画。
   想快用 M1，想远用 M8 加重复。
4. **一切都是可标定的。** 450 Hz 与 1250 Hz 两根导频相隔 32 个音间距，
   收发频偏能精确解出；控制信道给出每一行的起点，不靠猜。
5. **可以躲。** 默认占 800–1175 Hz（400 Hz 宽），另有整体压到 1 kHz 以下的共存布局，
   给同频段的数据模式让路。

## 频谱长什么样

```text
 450        620        800 ─────────── 1175   1250
  ●──────────●──────────●─●─●─ … ─●─●─────────●      Hz
 导频 P1   控制信道     16 个视觉音（25 Hz 间隔）   导频 P2
```

在瀑布图上：横轴频率、纵轴时间。一个汉字占 16 行（16 个时间片），
每一片里亮起的那几个音就是这一行的笔画；每个字开头还有一条更低的短亮线（边距音），
用来对齐字头。

## 档位

| 档位 | 单字时长 | 特点 |
| --- | --- | --- |
| M1 | 0.68 s | 最快，要求信号干净 |
| **M2（默认）** | 1.36 s | 日常通联的平衡点 |
| M4 | 2.72 s | 弱信号、QRP 常用 |
| M8 | 5.44 s | 极限条件，配合重复 |
| 24-M4 | 4.00 s | 24 音清晰档，笔画更细 |
| 16N-M4 | 3.63 s | 共存布局，整体压到 1 kHz 以下 |

## 配套软件

Windows 桌面程序，一页界面加一个独立窗口：

- **接收**：选声卡输入，实时瀑布滚起来，肉眼读字；控制信道自动带出呼号与网格；
  右侧存档区保留最近若干个 10 秒块，不暂停也能回看前几块。
- **发射**：输入报文（ASCII 自动转全角）、选档位，按 UTC 整十秒对齐播出，可中途打断。
- **原始瀑布图**：独立窗口，横轴频率、时间自上而下流（SDR 那种流水），
  用于检查设备是否正常、以及主界面读不出来时人工判读。
- **电台联动**：通过 Hamlib 支持 260 余种型号的 CAT 读写频率与自动 PTT。
- **通联日志**：呼号/网格/频率逐条记录，导出标准 ADIF 3.1.4。

## 怎么开始

1. 下载安装包（`cp16plus-B0.1.1-<日期>-安装包.exe`），装完桌面有快捷方式。
2. 电台调到常用频点，音频线（或 USB 声卡）接到电脑，软件里选对输入设备。
3. 先用 **M4 + 重复 1** 试水：慢一点更容易读，链路通了再提速。
4. 判读困难时：调大主界面"行高"，或打开"原始瀑布图"把行高调到 4×/8×；
   仍然读不出就换更慢的档位或加大重复。
