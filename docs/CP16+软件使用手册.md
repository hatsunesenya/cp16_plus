# CP16+ 软件使用手册（β0.1.1）

CP16+ 频谱书写的配套软件：把汉字发到频谱上、用肉眼从瀑布图里读出来。
软件版本 **β0.1.1**（发行标记 B0.1.1），协议版本 **V1**，作者 BD8DQS（BD8DQS@163.com）。

---

## 1. 能做什么

| 功能 | 说明 |
|---|---|
| 接收 | 用声卡的输入（电台耳机/线路输出）实时看瀑布，肉眼读字；也能回放 WAV |
| 识别 | 控制信道自动读出呼号、网格、字符数，给出参考判读结果 |
| 发射 | 编码成音频，按 UTC 整十秒对齐播出；可联动电台自动 PTT |
| 原始瀑布图 | 独立窗口，看整段音频的原始电平，用于检查设备、或主界面读不出时人工判读 |
| 通联日志 | 记录呼号/网格/频率，导出标准 ADIF 3.1.4 |
| 存图 | 按设定的时长保存瀑布图 PNG |

## 2. 安装

1. 双击 `CP16Plus-测试版-安装包.exe`。
2. 先读提示页（软件来历、协议版本 V1、软件版本 β0.1、联系方式），点「同意并继续」。
3. 再读 MIT 许可全文，点「我已阅读并同意」。
4. 选择安装位置：默认 `C:\Program Files\CP16Plus`，也可自选（会记住上次的选择）。
5. Windows 会弹出 **UAC** 提权提示，点「是」（安装需要管理员权限）。
6. 装完桌面与开始菜单都有 `CP16+ 测试版` 快捷方式。

静默安装（批量部署）：

```
CP16Plus-测试版-安装包.exe --silent --dir "D:\Tools\CP16Plus"
   可选 --no-shortcut（不建快捷方式） --no-launch（装完不启动）
```

卸载：`设置 → 应用 → CP16+ 测试版`，或运行安装目录里的 `卸载 CP16+ 测试版.exe`。
设置与日志按用户保存，卸载不会删掉通联日志。

**系统要求**：Windows 10/11 64 位；一块能用的声卡；要联动电台时需要 USB 串口（CAT）。

## 3. 界面速览

顶栏从左到右：`CP16+ 频谱书写 β0.1 · 协议 V1` → `主界面` / `原始瀑布图` / `电台` →
`频率 kHz` → 状态气泡 → `保存瀑布图` → `设置` / `通联日志` / `DEBUG`。

主界面分两栏：**左边接收**（瀑布 + 存档区），**右边发射**（报文、预览、发射按钮）。

---

## 4. 接收

1. 在「设置 → 音频」里选**输入设备**（电台的 USB 声卡或声卡线路输入）。
2. 点「开始接收」。瀑布开始滚动，底部显示 `t = x.x s` 与电平。
3. 左侧滑块：**行高**（格子大小）、**亮度**、**配色**（Inferno/青/琥珀/灰）。
4. 读字方法：纵轴频率、横轴时间；一个字占 16 格宽，笔画是其中的亮点。
   每个字开头有一条低于 16 音区的短亮线（边距音），用它对齐字头。
5. 右侧「存档区」保留最近若干个 10 秒块（默认 3 块），不必暂停就能回看前几块；
   块头标注 `−N / 时间区间 / 字数`。块数在「设置 → 显示」里改。
6. 也可以把 WAV 直接拖进窗口回放，走同一套渲染与判读逻辑。

**判读不出来时**：把档位调慢（M4/M8）、把重复次数 R 调大、或打开「原始瀑布图」人工比对。

---

## 5. 发射

1. 右侧输入报文（ASCII 会自动转全角，因为字库只有 16×16 全角字形）。
2. 选档位 `M1 / M2 / M4 / M8 / 16N-M4 / 24-M4`；默认 M2。
3. 点「发射」。软件会等到下一个 **UTC 整十秒**开始发送（同步帧始终叠加），
   发射过程中按钮变成「中断发射」。
4. 「生成 WAV」把这段音频存成文件，便于离线试听或用别的设备播放。
5. 「发→收自检」在本机内部走一遍编码→解调，验证链路。

发射时长 = 字符数 × 单字时长（M2 约 1.36 s/字）。整十秒对齐保证与接收端同步帧对齐。

## 6. 电台联动（CAT / PTT）

「电台」页：

1. 型号（Hamlib，264 个型号，可搜索 `X6100`、`IC-7300`、`FT-991` 等）。
2. CAT 串口（自动列出本机串口，协谷 X6100 选它的 USB 串口）。
3. 波特率按电台菜单里的 CAT 速率填；填错也不要紧，软件会用
   19200 / 9600 / 38400 / 57600 / 115200 / 4800 依次尝试，成功的那档自动写回。
4. 勾「启用 CAT」后点「测试 CAT 连接」：不发射，只读一次频率和 PTT，把结果写出来。
5. 发射时按「PTT 提前」拉 PTT、按「松开延时」松开；发射期间每 2.5 秒补发一次 PTT，
   避免个别机型中途自己松掉。关软件会先松 PTT。
6. **频率只在主界面顶栏设置**：改完自动下发给电台，同时作为通联日志里 ADIF 的 FREQ。
   「读频率」把电台当前频率取回并同步到顶栏。

> 串口是独占的：JTDX、日志软件等正在用同一个口时，本软件会报"串口打不开（被占用）"，
> 请先关掉它们。

## 7. 原始瀑布图（独立窗口）

顶栏点「原始瀑布图」会**另开一个窗口**（任务栏独立一项），里面是整段音频的原始电平，
    呈现方式和 SDR 软件一致：

- **横轴是频率**（从左到右升高）、**时间自上而下流**；纵轴方向与字的点阵一致，
  所以文字在图上呈正立方向，可以照着认字；
- **1 帧 = 1 条线，不做压缩**：每 20 ms 采一行频谱（50 行/秒），历史自然向下滚出画面，
  不会把很多历史挤进一屏；
- 「行高」可以选 1×/2×/4×/8×：把每条线占的像素行数加倍（纯复制，不做插值），
  字迹太扁时调大，看得更清楚；
- 范围可调：全带 0–4000 Hz、协议带 200–1500、低段 0–1500、16 音 800–1300，或自定义；
- 底部频率刻度、右侧 dBFS 刻度、左侧时间刻度；鼠标移到图上显示「频率 · 电平 · 时间」；
- 顶部 RMS / 峰值电平条，用来判断设备是否在正常采集；
- 「清屏」清掉已有画面重新开始，「存图」导出 PNG。

这个窗口只在打开时计算频谱，关掉即停，不占 CPU。

## 8. 通联日志与 ADIF

「通联日志」里每条记录包含呼号、网格、频率、日期时间、模式、备注；
呼号与网格能从控制信道自动带入，也可以手动改。

「导出 ADIF」生成标准 **ADIF 3.1.4** 文件（`MODE = CP16`，副模式为档位），
可直接导入 N1MM、Log4OM、Cloudlog 等日志软件。呼号为空的行不会被导出。

## 9. 文件与设置

| 项 | 位置 |
|---|---|
| 程序 | 安装目录（默认 `C:\Program Files\CP16Plus`） |
| 设置 | `%LOCALAPPDATA%\CP16Plus\settings.json` |
| 通联日志 | `%LOCALAPPDATA%\CP16Plus\qso.json` |
| 保存的图 / WAV | 「设置」里指定的输出目录（默认"文档\CP16Plus"） |
| 诊断日志 | `设置 → DEBUG`（也可导出） |
| 安装日志 | `%TEMP%\cp16plus-setup.log` |

「设置」里可改：音频输入/输出设备、呼号、网格、输出目录、发射时差补偿（±5 s）、
存档块数、瀑布图保存时长（15/30/自定义秒）、默认报文、调试模式。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 双击后没有窗口 | 确认已安装且浏览器可用；Edge/Chrome 均支持。若用了安全软件拦截，允许其启动子进程 |
| 窗口能开但点按钮没反应 | 旧版本缺陷，装当前版本即可；地址栏加 `#static-selftest` 可自检 |
| 瀑布一直是黑的 | 检查输入设备是否选对、电台音量/声卡增益是否太低；用「原始瀑布图」看噪声底 |
| 字能看见但读不出 | 换更慢的档位（M4/M8）、加大重复 R、把主界面行高调大；或用「原始瀑布图」把行高调到 4×/8× |
| 「测试 CAT 连接」报串口打不开 | 串口被别的软件占用、端口号选错、或驱动未装；提示里会显示实际用的串口与速率 |
| 发射到一半电台停了 | 已内置 PTT 保活；若仍出现，检查电台菜单里的 TX 时限 / VOX 设置 |
| 桌面或开始菜单没有快捷方式 | 用安装包重装一次；或在开始菜单搜索 `CP16+`；安装目录里有 `cp16plus.ico` 可自建 |
