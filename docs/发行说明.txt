CP16+ 测试版（浏览器应用窗口）
================================

两种用法，随便挑一种：
  · 「CP16Plus-测试版-安装包.exe」双击 → 装到本机 → 桌面/开始菜单入口（推荐）
  · 或者解压 zip，双击里面的「CP16+ 测试版.exe」直接用（绿色，不写注册表）
不需要 .NET、不需要联网、不需要 Node。
（界面用本机已有的 Edge / Chrome 显示；两个都没有时退回系统默认浏览器。）


界面
----
  · 程序、安装包、快捷方式、浏览器标签页统一用 CP16+ 图标
    （深青底：左边瀑布行、右边点阵字块），安装目录里也放了一份 cp16plus.ico 可自取。

版本
----
  · CP16+ 协议版本：V1
  · 软件版本：β0.1

零、安装包做了什么
-----------------
默认装到：%ProgramFiles%\CP16Plus\

安装是三步走：
  1) 先读一段说明（软件来历、协议版本 V1、软件版本 β0.1、联系方式、73）；
  2) 再读 MIT 许可全文（含随包 Hamlib 的 LGPL-2.1 说明），点「我已阅读并同意」；
  3) 最后选安装位置：默认 %ProgramFiles%\CP16Plus，点「否」可自己挑（会记住上次的选择）。
  任何一步点「不同意」都会直接退出，不会往磁盘写任何东西。

  · **安装需要管理员权限**：双击后会弹 Windows 的 UAC，点「是」即可；
    取消 UAC 会提示"需要在 UAC 提示里点是，或右键以管理员身份运行"；
  · 因为要管理员权限，程序装在机器级的 Program Files，快捷方式建在
    「所有用户」的开始菜单与公共桌面（当前用户桌面也会建一份）；
  · 卸载入口写在 HKLM 的「设置 → 应用」里，卸载同样需要管理员权限；
  · 建两个快捷方式（桌面 + 开始菜单），用的是系统的"已知文件夹"接口，
    所以桌面被 OneDrive 重定向、或系统是中文桌面名，也能找到正确位置；
    建完会校验，没建上会在完成提示里直接说明，并给出可执行文件路径与日志位置；
  · 在 HKCU 的卸载项里登记，所以「设置 → 应用 → 已安装的应用」里能卸载；
  · 装完自动启动一次。
卸载：
  · 设置 → 应用 → CP16+ 测试版 → 卸载；或
  · 直接运行安装目录里的「卸载 CP16+ 测试版.exe」。
静默安装（批量部署）：
  CP16Plus-测试版-安装包.exe --silent --dir "D:\Tools\CP16Plus"
  可选：--no-shortcut（不建快捷方式）--no-launch（装完不启动）
  自检快捷方式链路（不安装，只建一个测试快捷方式）：
  CP16Plus-测试版-安装包.exe --test-shortcut "D:\test-out"
装不上时看日志：%TEMP%\cp16plus-setup.log（TEMP 不可写时在安装包旁边）。


一、两个 exe 分别是什么
----------------------
CP16+ 测试版.exe   启动器：挑端口、静默拉起引擎、开一个没有地址栏的应用窗口。
                  窗口关掉，引擎跟着退出，不会留后台进程。
cp16plus.exe       引擎：内置 HTTP 服务 + 采集 + 解码 + 编码 + 发射，也是命令行工具。

两个文件必须放在同一个目录里。


二、界面
-------
顶栏左边是三个页面：**主界面 / 原始瀑布图 / 电台**；右边依次是频率输入、收发状态、
「保存瀑布图」，以及 设置 / 通联日志 / DEBUG 三个入口。
频率填 kHz（例如 14074），只用于通联日志的 ADIF 内容（FREQ = 14.074 MHz），
不参与调制解调——协议的频段是固定的 16 个音。

左栏（主）：收信
  · 「开始接收」直接听声卡，逐行实时出图；
  · 中间窄条是实时瀑布：横向 16 列 = 16 个音，纵向 = 时间，越往下越新；
  · 右侧「存档区」把已经收完的 10 秒块留下来（默认 3 块 = 最近 30 秒）；
    每块**竖排**（字自上而下按原始顺序），块与块之间按时间从左到右排列，
    块头标 −N / 时间区间 / 字数；采集不用暂停就能回看前几块；
  · 想换成 1–4 块，在 设置 → 显示 里调；
  · 行高 / 亮度 / 配色随时可调；
  · WAV 拖进窗口即可回放（走同一条流水线，逐行上屏）。
  · 参数细节、协议常量、信号电平这一版都不显示了——只留能用的东西。

右栏：原始瀑布图（点顶栏的「原始瀑布图」，会另外开一个窗口）
  · 画的是**整段音频的原始电平**：横轴时间、纵轴频率、颜色就是每个频点的 dBFS，
    不做字形切分、不做音调对齐，用途是确认设备有没有在正常采集、以及主界面读不出来时
    自己肉眼认字；
  · 频率范围可调：全带 0–4000 Hz / 协议带 200–1500 / 低段 0–1500 / 16 音 800–1300，
    也可以自定义起止（最小间隔 50 Hz）；
  · 左侧频率刻度、右侧 dBFS 刻度、底部时间刻度；鼠标移上去直接显示「频率 · 电平 · 时刻」；
  · 顶部有 RMS / 峰值 dBFS 电平条，设备是不是在工作一眼就看出来；
  · 「暂停」后可用滚轮往回翻历史（默认留 3000 帧 ≈ 3 分钟），双击图恢复实时；
  · 「存图」把当前这张图存成 PNG 到设置里的保存目录。
  · 它只在窗口开着的时候才算频谱，关掉就停，不占用 CPU。

发信
  · 报文输入 + 点阵预览（字库里没有的字会标出）；
  · 默认消息按钮：点一下就整条发出去（默认 CQ / 呼号 / 网格 / TEST / 73，
    改完呼号网格后在设置里「按呼号重建」即可）；
  · 「发射」遵守时序：**不到整十秒不发射**，界面会显示还有几秒；
    发射途中按钮变成「中断发射」，可以随时打断；
    早/晚都能调，见设置里的「时差补偿」；
  · 同步帧默认叠加；只有打开调试模式才出现开关。
  · 「生成 WAV」「发→收自检」也只在调试模式里显示。

设置（顶栏 → 设置）
  · 本台信息：呼号、网格（保存后按呼号重建默认消息）；
  · 音频：**输入设备（收信）和输出设备（发射）都在这里选**，
    另有"输入走系统混音"开关（抓电脑正在播放的声音）；
  · 发射时序：时差补偿（毫秒，可负），补偿射频链路 + 声卡的总延迟；
  · 文件：生成文件（WAV / 瀑布图 / ADIF / 日志）的保存目录，
    以及「保存瀑布图」默认截取多长（15 s / 30 s / 60 s / 自定义，默认 30 s）；
  · 显示：存档区显示几个 10 秒块（1–4，默认 3）；
  · 调试模式：显示生成 WAV、发→收自检、同步帧开关。

电台（顶栏第三个页面）：CAT 已接线
  · 协议由 Hamlib（与 JTDX 同源）负责，界面只做映射：型号（264 个）/ 串口 / 波特率；
  · **频率不在这里改**：主界面顶栏那个「频率」是唯一入口，改完自动下发给电台并进通联日志；
  · 「测试 CAT 连接」：不发射，只读一次频率/PTT，把每一步结果写出来，失败时指明原因；
  · 发射期间不再向电台发 CAT 读频率（每秒一条的轮询会打断某些机型的发射），
    并且每 2.5 秒补发一次 PTT，避免"电台自己在第 10 秒松掉、软件还在放音"；
    鼠标停在右上角"发射中"上能看到补发次数；
  · 勾「启用 CAT」后：发射前按"提前量"拉 PTT、播完按"松开延时"松 PTT；
    关软件、重连、点「按一下 PTT」超过 30 秒，都会自动松 PTT；
  · 「读频率」把电台频率取回并同步到顶栏那个频率框（也就是进 ADIF 的那个值）；
  · 电台频率每 1.5 秒自动刷新（只读显示，不会改你的设置）；
  · libhamlib-4.dll 随包发布（LGPL-2.1，动态链接，可自行替换成别的 Hamlib 构建）；
  · 没有电台也能试：型号选 Hamlib → Dummy，串口随便填，读写频率/PTT 都能走通。
  · 协谷 X6100：型号搜 “X6100”，串口选它枚举出的那个 COM 口，波特率按机器菜单里的
    CAT 速率填（原厂默认 19200）；填错也不会白费——程序会用 19200/9600/38400…
    挨个试，试通的那档自动写回设置。
  · 提示里会写「实际串口 / 速率」，如果这两个和你选的不一样，说明另一个软件（JTDX、
    日志软件）正占着串口——先把它们关掉再连。

通联日志（顶栏）
  · 收到 HDR 时自动登一条（备注标"自动（机读层）"），呼号/网格就是机读层解出来的；
  · 频率取顶栏当前值，表格里可逐条改；
  · 可以直接在表格里改，也可以手动「新增一条」；
  · 「导出 ADIF」按 ADIF 3.1.4 写一份 .adi 到保存目录（含 FREQ）。

DEBUG 日志（顶栏）
  · 显示本次运行的记录（会话、发射、保存、错误），「导出」写成 txt 到保存目录。


三、快捷键
---------
  空格      开始 / 停止接收
  S         保存瀑布图
  T         明暗主题


四、报文用字说明
---------------
字库是 GB2312（7445 字），**不含半角英文/数字**。所以发报文时界面会自动把
ASCII 转成全角（"CQ CQ DE BH4XYZ" → "ＣＱ ＣＱ ＤＥ ＢＨ４ＸＹＺ"），
人眼照样读得出来；呼号、网格本来就走在机读层（HDR），不占字的像素。


五、命令行（仍然是同一个 exe）
----------------------------
  cp16plus.exe serve --port 8770 --open     起界面（--open 直接开应用窗口）
  cp16plus.exe tx "文本" --out out.wav --mode M2 --sync
  cp16plus.exe rx 录音.wav --json out.json --png preview.png
  cp16plus.exe stream 录音.wav --verify
  cp16plus.exe audio --list                 列输入设备
  cp16plus.exe audio --device "USB Audio Device" --seconds 30
  cp16plus.exe check 目录名
  cp16plus.exe golden 目录名
  cp16plus.exe version

调试用地址参数：`#settings` `#qso` `#debug` 直接开对应对话框，
`#dark` 暗色，`#static` 不连实时流（截图/回归用）。

七、排障
-------
0) 装完之后窗口能打开，但点按钮没反应？
   · 这是某一版界面脚本的 bug（已修）。装最新这一版即可；
   · 想确认：地址栏在 127.0.0.1:8770 后面加 `#static-selftest`，
     页面会把自检结果写在标题栏区域（正常应是 tabs/settings/qso/freq/rawParams 全 ok）。

1) 双击后没窗口
   · 看 exe 目录下的 launcher.log；
   · 手动跑：cp16plus.exe serve --port 8770 --open（会打印原因）。

2) 设备列表是空的
   · 系统没有任何输入/输出设备被 Windows 暴露；
     在「声音设置」里启用麦克风/线路后重启程序。

3) 点「开始接收」提示打不开设备
   · 设备被独占、格式不支持或权限不足；换一个设备试。

4) 发射没有声音
   · 检查设置里的"输出设备"是不是接电台/发射机的那块声卡；
   · 界面下方会显示发射状态，失败会给出原因。

5) 想抓电脑正在播放的声音
   · 设置里勾"输入走系统混音"，程序会自动去找「立体声混音」设备；
     找不到说明系统没启用它。

6) 界面显示不正常 / 想用别的浏览器
   · cp16plus.exe serve --port 8770，然后手动开 http://127.0.0.1:8770/


八、反馈什么最有用
-----------------
1) 用的是哪种输入/输出（麦克风 / 线路 / SDR 虚拟声卡 / 电台 USB 声卡）
2) 解不出时的原始 WAV
3) 瀑布图（顶栏「保存瀑布图」导出的 PNG）——"看着像字但读不出"最有用
4) DEBUG 日志导出
